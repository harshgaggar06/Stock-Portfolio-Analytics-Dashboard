# 📈 Stock Portfolio Analytics Dashboard
An end-to-end **Stock Portfolio Analytics** project built using **Excel, MySQL, and Power BI**. This dashboard helps investors monitor portfolio performance, analyze investment allocation, track transactions, evaluate returns, and gain insights into portfolio risk through interactive visualizations.

---

## 📌 Project Overview
Managing investments across multiple stocks can make it difficult to track portfolio performance and identify opportunities. This project transforms raw transaction and stock market data into an interactive Power BI dashboard, enabling users to monitor investments, portfolio allocation, profitability, market trends, and sector-wise exposure in one place.

---

## 🎯 Objectives
- Analyze total investment across multiple stocks.
- Track current portfolio value and returns.
- Monitor capital deployment over time.
- Evaluate stock-wise and sector-wise allocation.
- Identify top-performing holdings.
- Analyze transaction history and investment trends.
- Visualize historical stock performance and market data.
- Build an interactive dashboard for better investment decisions.

- Information Technology represents the highest portfolio allocation.
- Capital deployment varies significantly across different investment periods.
